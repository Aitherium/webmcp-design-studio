# Demo video — ~2:30 script outline (2026-09-01)

Format: title cards + live captures (aitherbrowser in WebMCP-enabled Chrome,
the real site). Music bed. Owner VO or TTS.

## Beats

**0:00 — Open card.** "The WebMCP Design Studio — a browser agent that makes
things with you, not for you."

**0:10 — The protocol is the product.** Live capture: studio.aitherium.com
loads. The StatusBar shows 15 live tool chips. Zoom the ProtocolFeed: a
register burst as the agent boots, then toolchange as consent state opens.
VO: "Every tool the agent has is registered through the WebMCP protocol —
you can watch the protocol work, not just the UI."

**0:40 — Ask the agent.** Capture: "make a flyer for the Dark Matters
premiere" — the agent calls iris-generate; the request shows in the feed
with input + timing. The image lands on the canvas. VO: "The agent
generates through the studio's real render pipeline — the same one that
runs in production."

**0:55 — Consent.** Capture: a second edit is queued — the approve-batch
panel shows exactly what will change. Click Approve. VO: "Every edit waits
for you. The batch shows its work before anything changes."

**1:15 — The production studio.** Capture: ask the production-log tool —
"what did the studio produce this week?" — the log returns: 6 characters,
safety-screened, live. Cut to the pieces (moika, cassian, verity, naomi,
the warden). VO: "This studio doesn't just demo — it ran for a week as a
real production line. The agent can tell you what it made."

**1:50 — The safety ceiling.** Card: "every render is rated before it
counts" — show the refused-render line from the log (the warden, twice
refused for rating suggestive). VO: "Nothing ships unscreened. The rater
is fail-closed — if it can't judge, nothing passes. We measured that this
week: it refused pieces outright."

**2:15 — Close card.** "A protocol you can watch. A studio that produces.
A ceiling that holds. WebMCP Design Studio."
